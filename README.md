# DBD Challenge Roulette

Generador de builds aleatorias de perks para Dead by Daylight mediante una ruleta interactiva.

## Estado actual: Fase 1 — Base del proyecto

- Vite + React + TypeScript + Tailwind configurados.
- Tipos de dominio (`Perk`, `BuildSlot`).
- Dataset inicial de perks (survivor/killer) en `src/data`.
- Utilidades de aleatoriedad y portapapeles.

## Arranque local

```bash
npm install
npm run dev
```

## Próximas fases

2. Selección de rol (Survivor / Killer).
3. Grid de 4 casillas.
4. Ruleta funcional.
5. Integración build + ruleta.
6. Configuración (sonidos/animaciones/espacio vacío).
7. Botones finales (Nueva Build, Copiar).
